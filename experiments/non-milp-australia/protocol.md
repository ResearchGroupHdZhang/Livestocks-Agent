# 澳大利亚非全局 MILP 横向对比协议

状态：结果前锁定。只比较非全局 MILP 方法；美国 weighted MILP 后台任务不属于本实验，也不因本实验暂停或修改。

## 问题与范围

先在澳大利亚国家尺度运行相同的牲畜重布局问题，使用已经验证的 `aus-30.xlsx` 与 `aus-50.xlsx`。两份数据仅氨容量不同；地区、库存、六类生产系统及其顺序保持一致。

比较五种县对选择器：

1. `Random`：在当前动态 mask 的可行县对中均匀抽样。
2. `Greedy`：枚举当前可行县对，用同一个确定性数量分配器生成迁移量，以原 PPO 的即时决策分数选择最大者；并列时选最小 action ID。
3. `SA-priority`：模拟退火搜索一个低维县对优先级规则；候选规则通过完整/限步轨迹的累计原决策分数评价。
4. `GA-priority`：遗传算法搜索与 SA 相同的优先级规则和边界。
5. `Frozen PPO`：加载 `logs/v8/aus/best_model.zip` 的策略参数，只推理，不训练或微调；保持旧 checkpoint 的动作索引、前向语义和 mobility ratio。

SA/GA 明确称为“priority heuristic”，不虚称对全部路线排列进行精确元启发式搜索。五种方法只替换县对 selector；共享动态知识 mask、相同的 `amount_adapt` 数量 proposal/局部整数分配、相同约束复核、相同终止条件和输入。因而这是 selector 横评，不是纯算法端到端组件消融。

## 公平性锁定

- 六类生产系统：奶牛、肉牛、猪、绵羊、肉鸡、蛋鸡；严格使用各输入清单的实际列顺序。
- mobility ratio 使用澳大利亚 checkpoint 保存值 `0.1`；阈值 `[0, 0]`。
- 随机种子固定为 `42, 43, 44, 45, 46`。Random、SA、GA 跑五个种子；Greedy 为确定性单次；Frozen PPO 同时报告 deterministic argmax 单次与 stochastic 五种子。主表以 deterministic PPO 对确定性 Greedy、随机方法分布作比较。
- 所有方法的正式完成状态为动态 mask 耗尽；步数上限只可标记 `step_limit`，不能当完成解。
- 第一轮先运行 `256` 步计算与正确性 pilot，确认每种方法都实际执行、结果可回放、约束检查通过，再启动 mask 耗尽的正式运行。
- pilot 的 SA/GA 搜索预算分别为 24/24 条候选轨迹、每条候选 64 步；种群大小 6。该预算只用于验证执行链，不作论文结论。正式预算在 pilot 实测后按共同 wall-clock 预算锁定，避免预设对强化学习有利。

## 评价：不用“奖励越高=布局越好”

搜索算法可以使用原训练决策分数来产生轨迹，但论文优越性只由统一 evaluator 重算的物理终态指标决定；累计 reward 仅作诊断，不排名。

每个结果必须报告：

- 完成状态、执行步数、可行率、守恒误差、最大 N/NH3 违约；
- 源端 N 消解量与比例；目的端 N 容量使用；目的端 NH3 容量使用及净变化；
- 总迁移动物数和六类分量；受影响源/目的地区数；
- 低敏感度、低 PM2.5 关注目的地中的迁移量和比例；
- 源区剩余生产结构 share-L1；
- 首个可行解时间、selector 时间、局部整数分配时间、端到端时间、峰值 RSS；
- 任意截断结果仅比较“截至同一步数/同 wall-clock 的 anytime 曲线”，不与完整终态混为一列。

## 强化学习优势的判定

不预设 PPO 必胜。只有出现以下证据才写对应结论：

- **解质量优势**：PPO 在两种氨情景的 N 消解、环境落点和迁移规模 Pareto 关系上稳定优于 Greedy/Random/SA/GA，且没有关键约束或结构指标退化。
- **在线效率优势**：不含训练成本的 PPO 推理在相同硬件上更快达到同等或更好的物理指标；训练成本另列，并给出重复情景摊销。
- **情景复用优势**：同一冻结 PPO 在 30%/50% 两份新容量数据上均保持可行和竞争力，而 SA/GA 每个新情景需要重新搜索。
- 若 Greedy 或元启发式持平/更好，则不宣称 PPO 算法优势，改为报告知识 mask + 局部整数分配是主要贡献。

## 完成与失败规则

每个 run 单独保存配置、输入/checkpoint/code哈希、逐步迁移、结果、独立回放验证及错误状态。任何方法失败仍保留记录并继续其他方法。pilot 通过条件：10 个“方法×情景”主配置均至少有一个真实运行产物；所有产物可回放，且物理验证通过；无结果不得以模拟数据补齐。正式实验必须另写协议 amendment 后才启动。

## Pilot 后 Gate B 修订（结果前锁定）

Gate A 的真实 1-step 预检显示，精确 Greedy 每步全枚举需约 172 s，而 SA/GA 各自的 24×64 步搜索约需 430 s；直接要求所有方法跑满 256 步会把算法预算混成不公平的步数比较。因此 Gate B 采用双轨协议：

1. **同决策步数轨**：五种方法先各跑 16 个有效迁移步骤，30%/50% 情景都运行。Random/SA/GA 使用种子 42；Greedy 和 deterministic PPO 单次。用于核查短轨迹的物理质量方向，不作为终态排名。
2. **同 wall-clock 轨**：每个“方法×情景×种子”允许 3,600 s selector/search+rollout 预算，保存 60/300/900/1,800/3,600 s 的 incumbent/轨迹切片。Random、SA、GA 与 stochastic PPO 使用种子 42–46；Greedy 与 deterministic PPO 单次。
3. SA/GA 的初次 24×64 搜索成本计入 3,600 s，不把调参时间排除；Frozen PPO 同时另列历史训练成本，但冻结推理轨不重新训练。
4. 当前 runner 尚未实现 wall-clock checkpoint/中断续写，因此先运行 16-step 轨。正式 3,600 s 轨必须在实现、测试和真实中断恢复冒烟通过后启动。
5. 若 16-step 精确 Greedy 按当前速度超出 3,600 s，则以 3,600 s 到达的最后完整有效步骤作为结果，状态标记 `time_budget`，不得外推剩余步骤。
