# 论文方法 PPO 与认证 MILP 的同输入对比

更新时间：2026-09-08

## 结论

在能够严格匹配“第一阶段国家输入”的三个实例上，认证 weighted MILP 在其原生全局目标 $J=4\hat N-2\hat L+\hat E$ 下均优于归档论文 PPO：EU 和美国使用 PPO v9 作为同版本 confirmatory comparison；澳大利亚使用输入匹配的 PPO v8，作为版本限定的 robustness comparison。MILP 的 $J$ 相对 PPO 分别高 18.74%、8.86% 和 12.62%，并同时获得更高的源端 N 消解率、更高的归一化环境得分和更低的构成代理损失。

但这不是“PPO 训练失败”或“PPO 不如 MILP”的完整结论，因为二者原生优化目标不同。论文 PPO 使用逐动作奖励：

$$
R_t=4R_{NH_3,t}+2R_{sens,t}+R_{PM2.5,t},
$$

其中第一项是目的地氨容量使用的局部归一化奖励，后两项偏好低敏感度、低 PM2.5 目的地；PPO 选择源—目的县对，局部线性规划器决定六类牲畜数量。当前 MILP 则直接优化全局源端 N 消解、源区域构成代理和目的地环境。因此，表中的 $J$ 是对 PPO 最终布局的事后统一重评分，不是 PPO 的训练 reward。

更重要的是，当前归档 PPO 在 EU 和美国都未通过我们预先锁定的 MILP 物理可行性验证：目的地 N 和氨容量均只存在求解容差内的小残差，但源端 N guard 分别有 10 和 88 个超差行。最大单行超调都不到 1 kg，属于小数值残差而不是实质性大违约；然而在修复或定义统一容差前，不能把它标成与 MILP 完全等价的“严格可行”方案。

## 比较范围与版本

| 国家 | PPO 归档 | 输入 ID/顺序 | MILP 状态 | 是否进入主比较 |
|---|---|---|---|---|
| EU | `results/v9/eu` | 完全匹配 | 0.01008% gap，验证通过 | 是 |
| 美国 | `results/v9/usa` | 完全匹配 | 0.05723% gap，验证通过 | 是 |
| 澳大利亚 | `results/v8/aus` | 完全匹配 | 0.06635% gap，验证通过 | 已作为版本限定稳健性比较 |
| 中国 | `results/v8/cn` | 完全匹配 | 新 weighted 运行中，已有非零可行 incumbent | 等 MILP 证书 |
| 巴西 | `results/v8/br` | 完全匹配 | weighted 运行中 | 等 MILP 证书 |

EU/美国使用 v9，是因为这两个归档的最终 source/destination ID、行顺序和畜种列与 MILP 第一阶段输入完全一致。不能只按“最新目录名”选结果；`v9-2` 等目录属于不同空间范围或第二阶段输入。

## 主结果

### EU

| 指标 | 论文 PPO v9 | 认证 MILP | 解释 |
|---|---:|---:|---|
| 源端 N 消解率 | 93.7148% | 99.9995% | MILP 高 6.285 个百分点 |
| 达到 90% N 消解的源区域比例 | 92.8571% | 100.0000% | MILP 覆盖全部源区域 |
| 归一化环境得分 | 0.379724 | 0.798468 | MILP 高 110.27%（相对 PPO） |
| 源构成代理损失（低优） | 0.082090 | 0.045784 | MILP 低 44.23%（相对 PPO） |
| 真实剩余构成 share-L1（低优） | **0.384095** | 0.807357 | PPO 更好；暴露 MILP 代理失真 |
| 事后共同得分 $J$ | 3.964136 | **4.706878** | MILP 高 18.74%（相对 PPO） |
| 总移动量 | 24.41 亿只 | 33.02 亿只 | PPO 少 26.08% |
| 单只动物 N 消解 | **0.6462 kg** | 0.5097 kg | PPO 高 26.78% |
| 非零路线 | 253 | 622 | PPO 路线更稀疏 |

EU 的机制很清楚：MILP 为提高全局环境项和 N 项移动了更多动物，因此 $J$ 更高；PPO 使用更少路线和更少动物，单只动物的 N 效率更高。与此同时，MILP 的线性构成代理更优，但实际剩余 share-L1 明显更差，说明 current $J$ 会在接近清空源区域时高估“构成保持”。

### 美国

| 指标 | 论文 PPO v9 | 认证 MILP | 解释 |
|---|---:|---:|---|
| 源端 N 消解率 | 98.3531% | 99.9968% | MILP 高 1.644 个百分点 |
| 达到 90% N 消解的源区域比例 | 97.0976% | 99.9120% | MILP 更高 |
| 归一化环境得分 | 0.426554 | 0.625289 | MILP 高 46.59%（相对 PPO） |
| 源构成代理损失（低优） | 0.058388 | 0.002655 | MILP 低 95.45%（相对 PPO） |
| 真实剩余构成 share-L1（低优） | **0.170784** | 0.179173 | PPO 小幅好 4.68% |
| 事后共同得分 $J$ | 4.243900 | **4.619852** | MILP 高 8.86%（相对 PPO） |
| 总移动量 | 40.81 亿只 | 57.79 亿只 | PPO 少 29.37% |
| 单只动物 N 消解 | **0.7067 kg** | 0.5075 kg | PPO 高 39.25% |
| 非零路线 | 3,653 | 6,878 | PPO 路线更稀疏 |

美国表现与 EU 一致：MILP 在直接优化的全局指标上占优，PPO 在未被 $J$ 奖励的移动效率、路线稀疏性和真实构成上更有优势。两地都说明当前比较不是“一个指标定胜负”，而是目标函数选择决定了方案形态。

### 澳大利亚（PPO v8，版本限定稳健性比较）

| 指标 | 论文 PPO v8 | 认证 MILP | 解释 |
|---|---:|---:|---|
| 源端 N 消解率 | 96.0827% | 99.5814% | MILP 高 3.499 个百分点 |
| 达到 90% N 消解的源区域比例 | 91.6179% | 93.7622% | MILP 更高 |
| 归一化环境得分 | 0.098135 | 0.190269 | MILP 高 93.88%（相对 PPO） |
| 源构成代理损失（低优） | 0.124801 | 0.007875 | MILP 低 93.69%（相对 PPO） |
| 真实剩余构成 share-L1（低优） | 0.238005 | **0.006749** | 澳大利亚中 MILP 也明显更好 |
| 事后共同得分 $J$ | 3.691839 | **4.157772** | MILP 高 12.62%（相对 PPO） |
| 总移动量 | **0.574 亿只** | 0.992 亿只 | PPO 少 42.16% |
| 单只动物 N 消解 | **18.1552 kg** | 10.8838 kg | PPO 高 66.81% |
| 非零路线 | **1,124** | 1,977 | PPO 少 43.15% |

澳大利亚复现了 MILP 在 $J$、N、环境和构成代理上的优势，也复现了 PPO 少移动、少路线和单位动物 N 效率更高的趋势。与 EU/美国不同，澳大利亚 MILP 的实际 share-L1 也显著更好，说明“代理优但真实构成差”不是 MILP 的必然结果，而与接近清空源区域及具体库存结构有关。由于 PPO 是 v8，该结果支持跨版本方向一致性，但不能与 EU/美国合并成无条件的同版本均值。

## 可行性审计

| 国家 | 方法 | 守恒/路线聚合 | 目的地 N 超差 | 目的地氨超差 | 源端 N 超差 | 主表可标严格可行？ |
|---|---|---|---:|---:|---:|---|
| EU | PPO | 通过 | 0 | 0 | 10 | 否，待统一 guard/tolerance |
| EU | MILP | 通过 | 0 | 0 | 0 | 是 |
| 美国 | PPO | 通过 | 0 | 0 | 88 | 否，待统一 guard/tolerance |
| 美国 | MILP | 通过 | 0 | 0 | 0 | 是 |
| 澳大利亚 | PPO v8 | 通过 | 0 | 0 | 55 | 否，待统一 guard/tolerance |
| 澳大利亚 | MILP | 通过 | 0 | 0 | 0 | 是 |

PPO 最大源端 N 超调：EU 0.9989 kg，美国 0.9994 kg，澳大利亚 0.9949 kg。MILP 显式预留 1 kg source-N guard，因此它严格通过；PPO 输出接近零但未采用同一 guard。正式审稿比较有两种合理处理方式：

1. **严格口径（推荐主表）**：维持 1 kg guard，PPO 标为“near-feasible; small source-N residuals”，并进行最小可行性修复后再重评分；
2. **数值容差口径（补充表）**：预先定义所有方法统一的绝对/相对容差，重新审计，不可只为 PPO 临时放宽。

## 对论文主张的含义

当前结果不支持“PPO 的解质量优于有证书 MILP”。相反，在 MILP 的 $J$ 口径下，MILP 应当更优，而且实验也如此。当前结果支持三个更准确的结论：

1. **MILP 是可处理实例上的解质量上界参照。** EU、美国的结果验证了这一点。
2. **PPO 生成不同类型的方案。** 它使用更少动物、更少路线，单位动物 N 消解效率更高，并在真实构成 share-L1 上更好；但这些性质没有被当前 MILP 的 $J$ 充分奖励。
3. **若要论证 PPO 的科学价值，必须补运行时和泛化证据。** 需要报告 PPO 训练时间、单次推理和端到端解码时间，并在输入变化时测试 checkpoint 复用；不能只拿一次推理与 MILP 完整求解时间比较。

## 下一步

1. 对 PPO 结果执行不改变路线选择逻辑的最小可行性修复，消除小于 1 kg 的源端 N 超调；修复前后都保留。
2. 保留澳大利亚 v8 的版本限定标签，不将三国结果汇总成同版本均值。
3. 从训练日志或重新计时中补齐 PPO 训练、推理、局部 LP 解码和端到端时间。
4. 中国和巴西只在 weighted MILP 取得证书并独立验证后加入认证质量表；否则只用于可扩展性讨论。
5. 审稿回复应先报告这组同输入结果，再把主张改为“认证质量参照 vs 可扩展方案生成”，而不是宣称 PPO 在目标值上战胜 MILP。
